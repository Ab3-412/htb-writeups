# htb-writeups

I am new to pentesting and I am just sharing my progress. Any and all advice is welcomed.

## Repository Structure

```
htb-writeups/
├── README.md         # This file
├── TEMPLATE.md       # Writeup template to use for each machine
└── machines/
    └── <MachineName>/
        └── README.md # Writeup for that machine
```

## How to Use

1. Copy `TEMPLATE.md` into `machines/<MachineName>/README.md`
2. Fill in each section as you work through the machine
3. Replace flag values with `***REDACTED***` before publishing (machines must be retired to share flags)
